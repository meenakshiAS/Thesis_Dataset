# Thesis Dataset: Hallucinations in LLM-Generated Code Explanations

This repository contains the observational analysis data and supporting materials for a Master's thesis in Software Engineering at Blekinge Institute of Technology (BTH), Sweden. The study investigates hallucinations in explanations of Python source code generated by large language models (LLMs).

The purpose of making these materials available is to document the data collection, hallucination identification, and validation process used in the study.

## Repository Structure

The repository contains four main folders:

| Folder | Description |
|---|---|
| `Datasets/` | Source-code examples selected for the experiment. |
| `LLM-Outputs/` | Code explanations generated by the selected LLMs (ChatGPT and Grok). |
| `Hallucinations_Identified/` | Records of identified hallucinations, their classifications, and supporting observations. |
| `Validation/` | Materials documenting the evaluators' assessments of the identified hallucinations. |

## How to Use This Repository

1. Review `Datasets/` to examine the selected source-code.
2. Review `LLM-Outputs/` to inspect the explanations generated by the LLMs.
3. Review `Hallucinations_Identified/` to understand the identified hallucination cases and their classifications.
4. Review `Validation/` to examine evaluator assessments and supporting validation evidence.

The repository provides supporting research materials for inspection, rather than a complete automated reproduction pipeline.
